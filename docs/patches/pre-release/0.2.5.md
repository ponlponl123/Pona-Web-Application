# 🚀 Pona! Clean WebApp & Backend Engine Overhaul `0.2.5 (Pre-Release)`

[author-Ponlponl123]

`22 August 2026`

Welcome to **Pona! v0.2.5 (Pre-Release)** — our biggest and most ambitious release to date! Over the span of **105+ commits** on the `clean-webapp` branch and a deep architectural overhaul across our backend services, Pona has been completely rebuilt from the ground up for blistering speed, buttery-smooth animations, bulletproof real-time playback, and universal device compatibility.

---

## ⚡ What's New & Major Highlights

### 🏎️ 1. Architecture & State Management (Clean WebApp)
* **Zustand & Jotai State Architecture** — Eliminated global React Context overhead by moving to fine-grained Zustand stores (`coreStore`, `musicCacheStore`) and atomic Jotai state (`uiAtoms`), eliminating cascading re-renders across the entire web application.
* **Full Next.js App Router & Server Actions** — Modernized codebase structure (`/app`, `/app/g/[guildId]`, `/player`, `/history`, `/favorite`, `/status`, `/community`) with native Bun fetch and optimized standalone builds.
* **Metadata & Session Forwarding** — Server actions and API fetchers automatically forward browser telemetry (`user-agent`, `accept-language`, `x-forwarded-for`, `x-user-lang`, `x-user-country`, `x-user-timezone`, `sec-ch-ua*`, `x-ytmusic-cookie`) for localized, high-fidelity music streaming.
* **Real-time Bidirectional WebSocket Engine** — Guild-scoped Socket.IO communication with Redis adapter, delivering sub-millisecond playback synchronization and queue state broadcasts.

---

### 📱 2. Next-Gen Mobile Player & Touch Gestures
* **Multi-Stage Artwork Morphing** — Step-by-step swipe gestures (`0.0 ↔ 1.0 ↔ 1.5 ↔ 2.0`) featuring GPU-accelerated hero artwork morphing via Framer Motion `useTransform` with zero text-reflow jitter.
* **Coordinated Drag & Drop Reordering** — Embedded `@dnd-kit` sortable lists inside draggable swipe sheets with pointer displacement filtering (`isMovedRef` > 6px) to eliminate accidental clicks and gesture conflicts.
* **Screen WakeLock Support** — Native Screen Wake Lock API integration (`useWakeLock`) to keep your screen illuminated during active music playback.
* **Dynamic Viewport Height (`dvh`)** — Optimized mobile layouts to seamlessly fit mobile browser address bars and notch areas.

---

### 🎵 3. Music Player, Queue & PNPT (Pona Next Playing Track)
* **Interactive Drag-and-Drop Queue** — Seamlessly drag, reorder, and delete tracks within the active queue with animated visual feedback.
* **PNPT Autoplay & Recommendation Engine** — Synchronized origin track recommendations with one-tap "Move to Queue", auto-refill on track completion, and skip-to functionality.
* **High-Performance Synced Lyrics** — Real-time lyrics with memoized active line lookup, smooth auto-scrolling, source attribution, and graceful 404 fallback states for instrumentals.
* **Compact Player View** — Added a distraction-free compact player route (`/player/c`) with smooth background crossfades.
* **Premium Shiny Skeletons** — Replaced generic loading spinners with animated shiny shimmer skeletons across the Related tracks panel and browse feeds, mirroring exact layout structures with GPU-accelerated gradient highlights.

---

### 🎨 4. App-Wide Typography & Design Customization
* **Typography Suite** — Customize your font in Layout Settings with instant, zero-FOUC switching:
  * **Friendly (OG)**: `Ponlponl123 Article` (EN/TH) + `SN sana fon Maru J30` (JP)
  * **Business**: `Mona Sans` (EN) + `Pridi` (TH)
  * **Modern**: `Figtree` (EN) + `Noto Sans Thai Looped` (TH)
* **Proportional Typography Scaling** — Introduced `--font-scale` text tokens for standard fonts, scaling typography gracefully without distorting UI layout spacing, margins, or padding.
* **Tailored Themes** — Default, Chocolate, Matcha, Hopeful, Red Rose, Violet, Winter, Cupcake, NextUI, Dark, Light, and True AMOLED Black modes.
* **Customization Settings** — Transparency controls, acrylic effects, layout toggles, and customizable keybinds.

### 🌐 5. Legacy Browser Color Space Compatibility
* **PostCSS Color Fallbacks** — Integrated `@csstools/postcss-oklab-function` and `@csstools/postcss-color-mix-function` (`preserve: true`) into the PostCSS pipeline.
* **Universal Rendering** — Automatically emits fallback sRGB / `rgb()` / `rgba()` values alongside modern `oklch()` and `color-mix()` rules, ensuring pristine rendering on older Chrome, Safari, Firefox, and embedded WebViews.

### 📊 6. Redesigned Pages & Sub-Systems
* **Listen History Page** — Redesigned with server-side pagination, real-time query filtering, and listening analytics (unique tracks, total listen duration, top weekly artist).
* **Favorite & Top Artists Page** — Historical listening data aggregation, artist grid, subscribed artist management, and staggered blur entrance animations.
* **Artist Page & Hero** — High-resolution backdrop hero artwork, physics-based spring expandable biography with bottom gradient mask truncation, and YouTube channel subscription integration.
* **Status & Health Monitoring** — Parallelized health probes with `Promise.all`, multi-state Lavalink diagnostics (`operational`, `degraded`, `down`), regional latency metrics, and shard/cluster monitors.
* **Community Hall of Fame** — Community credits page rendering individual font typography previews, contributor badges, and translator recognition.
* **Guild Music Permissions** — Granular role-based controls for bot commands, volume adjustments, and playback actions.

---

### 🛠️ 7. Backend Infrastructure & Engine Stability
* **Lavalink Stabilization with POT & Cipher** — Upgraded YouTube plugin with Player Operations Token (POT) and cipher deciphering mechanisms, ensuring stable unthrottled streaming without playback drops.
* **InnerTube Clients Priority Re-Ordering** — Re-prioritized YouTube client fallback order (`MUSIC` → `ANDROID_VR` → `WEB` → `WEB_EMBEDDED_PLAYER` → `TVHTML5EMBEDDED`) for high-fidelity audio stream resolution.
* **Multi-Node Failover & NodeLink Support** — Dynamic node migration (`setNode`), candidate node fallback search iteration, and automatic player recovery during node disconnects or playback failures.
* **Lavalink Circuit Breaker & Resilience** — Implemented circuit breaker with backoff retries for track errors, voice gateway reconnect protection (Opcode 4), and transient voice state grace periods.
* **Multi-Node Health Evaluation** — REST `/v1/lavalink` endpoint probes WebSocket connectivity, active sessions, REST responsiveness (`/v4/info`), and CPU/frame load.
* **Database & User Session Persistence** — Fully migrated to Prisma ORM with persistent `user_session` models for visitor IDs, custom cookies, timezone, and locale metadata.
* **Multi-Engine Lyrics API** — Native TS YTMusic engine with fallback persistence, multi-artist support, and source attribution.
* **Redis Caching Layer** — Dynamic `REDIS_PREFIX` support, Redis Sentinel entrypoints, and cached endpoints for YouTube channel subscriptions and history stats.

### ⚡ 9. Ultra Performance & Low-End Optimization (Butter-Smooth UI)
* **Zero Layout & Computed Style Recalculations** — Eliminated expensive universal wildcard transition selectors; scoped transitions strictly to interactive elements using GPU-accelerated properties (`transform`, `opacity`, `color`, `background-color`, `border-color`, `box-shadow`).
* **Fluid Sidebar & Layout Transitions** — Restored soft cubic-bezier transitions on `.apply-long-soft-transition` for silky-smooth sidebar expanding/collapsing (`w-12 ↔ w-48`) and header search bar shifting.
* **Root Player Re-Render Decoupling** — Decoupled high-frequency `playbackAtom` state from root player containers (`PonaPlayer`, desktop & mobile panels). Playback clock re-evaluations are isolated directly to leaf controls (`PlayerSeekBar`, `PlayerControls`, `MobileTimeDisplay`), preventing 60fps cascading re-renders during audio playback.
* **High-Performance Ref-Based Lyrics Engine** — Replaced continuous 100ms React state updates with an internal `useRef` clock and $O(\log n)$ binary search lookup with boundary hysteresis, triggering component re-renders exclusively on active lyric line transitions.
* **Native Zero-Dependency Color Engine** — Replaced external color parsing libraries with native, ultra-fast mathematical color conversion (`hexToRgb`, `rgbToHsl`, `rgbToHex`, `generatePalette`) and in-memory caching for instantaneous accent color palette generation.
* **CORS-Safe Artwork Color Extraction** — Injected `Access-Control-Allow-Origin: *` into image proxy routes and added reactive `ponaCommonState.current` document synchronization to dynamically apply track accent colors (`--pona-app-music-accent-color-[50..950]`) across the entire web app.
* **Compiler & Tree-Shaking Package Import Optimization** — Enabled Next.js `optimizePackageImports` across 11 key UI dependencies (`@phosphor-icons/react`, `lucide-react`, `recharts`, `motion`, `@heroui/react`, `@heroui/styles`, `radix-ui`, `@dnd-kit/core`, `@dnd-kit/sortable`, `@dnd-kit/utilities`, `embla-carousel-react`), `compress: true`, and production `removeConsole`.
* **Repository-Wide Lint & Type Verification** — Cleaned unused imports, dead references, and expressions across 22+ files with 0 ESLint warnings and 0 TypeScript errors.

## 🐛 Bug Fixes & Refinements

* Fixed status page probe latency by switching from sequential awaits to concurrent `Promise.all` execution (up to 6x faster).
* Fixed 0-indexed `skipto` offsets when interacting with PNPT recommendation queues.
* Fixed Next.js `images.localPatterns` blocking local static assets under `/static/**`.
* Fixed desktop player bottom offset on smaller screen resolutions.
* Fixed voice gateway heartbeat timeouts on bot restarts by re-transmitting Gateway Opcode 4 on `ClientReady`.
* Fixed transient null channel ID voice state updates triggering premature bot disconnects.
* Fixed SQL `Unknown column 'created_at' in 'WHERE'` error in listening history queries.
* Fixed invisible settings button on app sidebar when collapsed.
* Fixed scrollbar color parsing when using CSS custom properties.
